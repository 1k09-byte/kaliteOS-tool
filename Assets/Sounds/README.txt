Benchmark cue sounds (pre-rendered WAVs, no runtime TTS).

Built-in beeps (generated by tools/GenBenchSounds.ps1, do not hand-edit):
  tick.wav        countdown tick
  start.wav       recording started (rising two-tone)
  tenleft.wav     10-seconds-left tick
  stop.wav        recording stopped (falling two-tone)
  saved.wav       run saved blip
  failed.wav      capture failed (low double-buzz)

Custom voice (optional, user-supplied):
  voice_started/stopped/failed/saved (.wav preferred, .mp3 accepted)
  plays for Started/Stopped/Failed/Saved when Sounds = Voice.
  WAV (any sample rate) or MP3 both work, keep each under ~2 s.
  Drop both files here, rebuild, and the Capture tab will report
  "Voice files found". When absent, Voice mode falls back to beeps.
  Tip: record "Recording started" / "Recording stopped" with Voice Recorder,
  or render offline with any TTS (this box has no speech runtime, so the
  repo cannot generate them: SAPI sapi.dll missing, WinRT speech needs
  package identity, en-US TTS capability install timed out).
